# ♛ The Crimson Sanctum

### A Realm Beyond the Ordinary

Welcome to **The Crimson Sanctum**, a Minecraft server landing page designed to introduce players to a fantasy-inspired multiplayer community.

Featuring a dark crimson, gold, and black aesthetic, the website provides visitors with an introduction to the server, highlights its community and adventure features, and makes joining easy with a one-click server address copy feature.

## Live Preview

- **Repository:** [The Crimson Sanctum](https://github.com/adriannaabner-collab/the-crimson-sanctum)
- **Minecraft Server:** `crimsonsanctum.sparkedservers.us`

## Features

- **Fantasy-Inspired Design:** Medieval-themed styling with crimson, black, and gold colors.
- **Navigation:** Easy access to Home, About, Features, and Join sections.
- **Server Information:** Displays the Minecraft server address.
- **Copy Server Address:** JavaScript clipboard functionality allows players to copy the server address with one click.
- **Feature Highlights:** Introduces adventure, community, and building opportunities.
- **Responsive Layout:** Uses CSS Grid and flexible sizing to accommodate different screen widths.

## Getting Started

You can view or run the website locally by following these steps.

1. Clone the repository:

```bash
git clone https://github.com/adriannaabner-collab/the-crimson-sanctum.git
```

2. Navigate into the project directory:

```bash
cd the-crimson-sanctum
```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.

## Joining the Server

Ready to enter The Crimson Sanctum?

Copy the server address:

```text
crimsonsanctum.sparkedservers.us
```

Add the address to your Minecraft multiplayer server list and connect using a compatible Minecraft edition and version.
